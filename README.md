# 한 표

한 공간에 모인 30~50명이 폰으로 투표하는 웹앱입니다. 운영자가 방을 만들고, 참가자가 QR이나 4자리 코드로 들어와 종이 용지에 직접 쓰거나 타이핑하고, 용지는 접혀서 투표함에 들어갑니다. 마감하면 운영자가 용지를 한 장씩 펼쳐 보고, 보기 전용 대화면에 같은 화면을 띄울 수 있습니다.

## 할 수 있는 것

- 운영자가 방을 만들고 QR 또는 4자리 코드로 참가자를 받는다. 계정이 없다.
- 투표를 만든다. 용지는 자유 기재(손글씨 또는 타이핑)나 객관식(보기 2~8개)이고, 익명이나 기명을 고른다.
- 제출하면 용지가 두 번 접혀 투표함에 들어간다.
- 마감하면 용지를 무작위 순서로 한 장씩 펼쳐 본다. 객관식은 "전체 공개"로 득표 그래프를 본다.
- 보기 전용 대화면 링크를 열 수 있고, 대화면 가리기와 전체화면을 지원한다.
- 결과를 CSV로 받고, 인쇄 화면에서 PDF로 저장한다.
- 쓰지 않은 방은 6시간 뒤에 지워진다.

익명 투표는 공개 화면에 이름이 표시되지 않는다는 뜻입니다. 서버는 작성자를 저장하고 운영자는 알 수 있습니다. 완전 익명이 아닙니다.

## 실행

Node 22 이상이 필요합니다.

```sh
npm install
npm run dev
```

`npm run dev`는 서버(3000)와 화면(5173)을 함께 띄웁니다. 브라우저에서 `http://localhost:5173`을 엽니다.

배포와 같은 방식으로 돌려 보려면 이렇게 합니다.

```sh
npm run build
npm start
```

`http://localhost:3000`에서 서버가 빌드된 화면까지 내줍니다. 폰으로 확인하려면 같은 와이파이의 주소나 `cloudflared` 같은 터널 주소로 열면 됩니다.

## 환경변수

| 이름 | 기본값 | 설명 |
|---|---|---|
| `PORT` | 3000 | 서버 포트 |
| `ROOM_TTL_MS` | 21600000 (6시간) | 마지막 활동 뒤 방이 지워지기까지의 시간 |
| `SWEEP_INTERVAL_MS` | 60000 | 지울 방을 훑는 간격 |
| `TRUST_PROXY` | 없음 | `1`이면 프록시 뒤에서 클라이언트 주소를 `X-Forwarded-For`에서 읽는다 |
| `ALLOWED_ORIGINS` | 없음 | 같은 호스트 말고 웹소켓 연결을 허용할 출처(쉼표로 구분) |

## 확인

```sh
npm test
npm run typecheck
```

화면과 실제 서버를 브라우저로 돌려 보는 스크립트는 `e2e/`에 있습니다. Windows의 Edge 경로가 스크립트에 적혀 있습니다.

```sh
npm run build
node e2e/lobby-real.mjs
node e2e/vote-real.mjs
node e2e/ink-real.mjs
node e2e/fold-real.mjs
node e2e/display-privacy-real.mjs
npx tsx e2e/lobby-visual.mjs
```

## 구조

| 폴더 | 내용 |
|---|---|
| `shared/` | 서버와 화면이 같이 쓰는 전송 규약, 검증 규칙, 손글씨 모양 |
| `server/` | 방 도메인(순수 함수), WebSocket, 방 수명, 시도 제한 |
| `web/` | React 화면 |
| `e2e/` | 브라우저로 돌려 보는 확인 스크립트 |
| `디자인가안/` | 구현 전에 만든 디자인 가안 3개(채택한 것은 A) |

서버가 방 상태를 메모리에 갖고, 역할(운영자, 참가자, 대화면)별로 서로 다른 스냅샷을 만들어 보냅니다. 익명 규칙은 그 스냅샷을 만드는 한 곳에서만 지켜집니다.

## 배포

Render 무료 플랜을 기준으로 `render.yaml`을 두었습니다. 저장소를 Render에 연결하고 Blueprint로 만들면 됩니다.

- 무료 플랜은 15분 동안 들어오는 트래픽이 없으면 잠들고, 다시 깨우는 데 약 1분이 걸립니다. 잠들거나 재시작되면 메모리의 방은 사라집니다. 행사 전에 주소를 먼저 열어 깨워 두세요.
- 데이터를 저장하지 않으므로 서버가 다시 시작되면 진행 중이던 방이 사라집니다. 결과는 마감 직후 내보내세요.
- 자동 배포는 꺼 두었습니다. 배포가 방을 지우기 때문입니다.
